# 2026 창조시기 생태달력

가톨릭 **창조시기(Season of Creation)** 를 함께 지내기 위한 대야미 성당의 정적 웹 달력입니다.
2026년 9월 1일부터 10월 4일까지 하루에 한 장씩, 그날의 기도문과 「찬미받으소서」 인용문, 그리고 실천 과제를 담았습니다.

**사이트**: https://bagemy.github.io/bada/

2026년 주제는 **「살아 있는 물」** 입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 달력 첫 화면. 34일치 날짜를 격자로 보여 주고 각 날짜 페이지로 연결합니다. |
| `2026-09-01.html` ~ `2026-10-04.html` | 날짜별 페이지 34개. 파일명이 곧 날짜(`YYYY-MM-DD`)입니다. |
| `2026창조시기기도문.html` | 기도문 전문 페이지 (독립 실행, 달력에서 링크되지는 않음). |
| `common.css` | **날짜별 페이지 34개가 공유하는 스타일시트.** |
| `2026_창조시기로고.png` | 첫 화면 배경 및 카카오톡 공유 이미지(og:image). |
| `대야미성당로고p.png` | 첫 화면 하단 로고. |
| `qrcode_bagemy.github.io.png` | 사이트 접속용 QR 코드 (인쇄·배포용). |

### index.html 의 동작

- 토요일은 파란색, 일요일은 빨간색으로 표시됩니다.
- 접속한 날짜가 달력 기간 안에 있으면 해당 칸이 초록색으로 강조됩니다.
- 위 두 가지는 `index.html` 하단의 인라인 스크립트가 처리합니다.

### 날짜별 페이지의 구조

모든 날짜 페이지는 같은 뼈대를 씁니다.

```html
<div class="container">
  <div class="prayer-section">   <!-- 2026 창조시기 기도 (전 페이지 공통) -->
    <div class="title">…</div>
    <div class="subtitle">…</div>
    <div class="verse">…</div>   <!-- 여러 개 -->
  </div>
  <div class="icon"></div>
  <h1>&lt;찬미받으소서&gt; 제N항</h1>
  <p>…인용문…</p>
  <h1>실천하기</h1>
  <p>…그날의 실천 과제…</p>
  <div class="back"><a href="index.html">← 돌아가기</a></div>
</div>
```

날짜마다 달라지는 부분은 `<title>`(N일차), 「찬미받으소서」 항 번호와 인용문, 그리고 실천 과제뿐입니다.

## 스타일 관리

날짜별 페이지 34개는 **`common.css` 하나만 고치면 전부 반영**됩니다.
예전에는 34개 파일 각각에 똑같은 `<style>` 블록이 복사되어 있었지만, 지금은 이렇게 참조합니다.

```html
<link rel="stylesheet" href="common.css">
```

`common.css` 가 정의하는 선택자는 다음과 같습니다.

`body` · `.container` · `h1` · `p` · `.icon` · `.prayer-section` (및 하위 `.title` `.subtitle` `.verse`) · `.back` · `.back a`

> **주의** — `index.html` 과 `2026창조시기기도문.html` 은 `common.css` 를 쓰지 않고 각자 인라인 `<style>` 을 유지합니다.
> 세 그룹이 `body`, `.container`, `.title`, `.subtitle` 같은 이름을 **서로 다른 값으로** 쓰고 있어서, 억지로 합치면 화면이 깨집니다.
> 나중에 통합하려면 클래스 이름부터 정리해야 합니다.

## 수정하는 법

**날짜 하나의 내용만 바꿀 때** — 해당 `2026-MM-DD.html` 을 열어 「찬미받으소서」 인용문과 실천하기 문단만 고칩니다.

**전체 디자인을 바꿀 때** — `common.css` 만 고칩니다.

**날짜를 추가할 때** — 기존 날짜 페이지를 복사해 파일명을 `YYYY-MM-DD.html` 로 맞추고, `index.html` 의 격자에 링크 한 칸을 더합니다. 오늘 날짜 강조 기능이 파일명에서 날짜를 읽으므로 **파일명 형식을 반드시 지켜야 합니다.**

## 배포

`main` 브랜치에 푸시하면 GitHub Pages 가 그대로 서비스합니다. 별도 빌드 과정은 없습니다.

```sh
git add .
git commit -m "메시지"
git push origin main
```

스타일을 고쳤는데 화면에 바로 반영되지 않으면 브라우저나 CDN 캐시 때문입니다.
그럴 때는 참조에 버전을 붙이면 됩니다: `common.css?v=2`
